Task 4 – Design Patterns Mini Project

This project demonstrates three common software design patterns using Java.

1. Singleton Pattern

- Problem solved: Prevents multiple instances of a class from being created.
- When to use: When one shared object is needed, such as a logger.

2. Factory Pattern

- Problem solved: Hides object creation logic.
- When to use: When creating different types of objects, such as email or SMS notifications.

3. Observer Pattern

- Problem solved: Notifies multiple objects automatically when information changes.
- When to use: When multiple subscribers need updates, such as news notifications.

Technologies Used

- Java
- JDK 17
- Visual Studio Code

How to Run

1. Open the project folder in VS Code.
2. Open "Main.java".
3. Run the Java file.
4. View the output in the terminal.

Project Files
