Task 4 – Design Patterns Mini Project

Overview

This project demonstrates three common software design patterns using Java.

1. Singleton Pattern

Problem solved: Prevents multiple instances of a class from being created.

When to use: When one shared object is needed throughout an application, such as a logger or configuration manager.

2. Factory Pattern

Problem solved: Hides object creation logic from the user.

When to use: When objects of different types need to be created based on a given condition, such as email or SMS notifications.

3. Observer Pattern

Problem solved: Notifies multiple objects automatically when information changes.

When to use: When several subscribers or components need updates, such as news notifications.

Technologies Used

- Java
- Visual Studio Code
- JDK 17

How to Run

1. Open the project folder in VS Code.
2. Open "Main.java".
3. Run the Java file.
4. View the output in the terminal.
